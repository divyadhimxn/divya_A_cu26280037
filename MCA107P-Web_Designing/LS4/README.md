## Run/setup notes for Kali Linux

1. Install the required stack: `sudo apt update && sudo apt install apache2 php libapache2-mod-php php-mysql`.
2. Start Apache: `sudo systemctl enable --now apache2`.
3. Copy PHP files into `/var/www/html/` (or a project directory served by Apache).
4. Run `3.1.sql` in MariaDB/MySQL to create `college_db`.
5. Configure `4.1.php` and save a copy as `db_connect.php` in the same served directory; replace the sample password with your own local database credentials.
6. Run `5.1.php` once to create the `students` table. Run `12.1.sql` and `19.1.sql` for the extra tables used by those questions.
7. `12.2.php` expects user records in `users`; insert users with a `password_hash` generated by PHP `password_hash()`.
8. `19.2.php` inserts into both `students` and `student_profiles`; use a unique email each run.
9. `13.1.php` stores uploads in an `uploads/` subdirectory. Ensure Apache can write to that directory, and never allow PHP execution inside uploads on a production server.
10. `10.1.txt` contains virtual-host configuration instructions. `18.1.sh` describes log testing. `20.1.sh` installs/checks PHP extensions.
