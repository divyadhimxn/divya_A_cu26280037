Linux Lab Sheet 5: vi/vim Editor
Subject Code: UAC02P
These are commands to type inside vi/vim, not a script to run as a shell script.

Q1. Create lab5.txt and enter at least five lines.
Terminal:
vim lab5.txt
Press i, type e.g.:
Linux Lab Practice
This is line two.
This is line three.
Searching and replacing text.
End of practice file.
Press Esc, then type :wq and press Enter.

Q2. Open an existing file and display its contents.
vim lab5.txt
Outside vim, display contents with:
cat lab5.txt
Sample output:
Linux Lab Practice
This is line two.
This is line three.
Searching and replacing text.
End of practice file.

Q3. Switch modes.
Normal mode: Esc
Insert mode: i (insert before cursor), a (append after cursor)
Command-Line mode: type : while in Normal mode, e.g. :w

Q4. Insert before and after cursor.
Normal mode: i inserts before cursor; a inserts after cursor.
Press Esc after typing to return to Normal mode.

Q5. Add a line below and above current line.
o = open a new line below; O = open a new line above. Press Esc to finish.

Q6. Save without exiting.
In Normal mode: :w then Enter.

Q7. Save and exit.
In Normal mode: :wq then Enter. Alternative: ZZ (Normal mode).

Q8. Exit without saving.
In Normal mode: :q! then Enter.

Q9. Beginning/end of line.
0 = first column; ^ = first non-blank character; $ = end of line.

Q10. Beginning/end of file.
gg = first line; G = last line.

Q11. Delete character, word and line.
x = delete character under cursor
dw = delete from cursor through a word
dd = delete current line

Q12. Copy current line and paste below.
yy then p

Q13. Copy multiple lines and paste elsewhere.
Put cursor on first line, type 3yy to copy three lines, move cursor, then p.

Q14. Search forward and move between matches.
/specified_word then Enter; n = next match; N = previous match.

Q15. Search backward.
?specified_word then Enter; n/N move between matches (direction depends on search).

Q16. Replace first occurrence on current line.
:s/old/new/ then Enter

Q17. Replace all occurrences throughout the file.
:%s/old/new/g then Enter
To ask for confirmation for each replacement: :%s/old/new/gc

Q18. Undo and redo.
u = undo; Ctrl-r = redo.

Q19. Show line numbers and jump to a line.
:set number
:set nonumber turns them off
Ctrl-g shows file and cursor position
10G or :10 jumps to line 10.

Q20. Complete workflow (commands in order):
vim lab5.txt
i (enter or edit text)
Esc
/word (search)
:%s/old/new/g (replace; adapt old/new)
yy then p (copy/paste a line)
:w (save)
:q (exit if no unsaved changes)
For changes, :wq saves and exits.
