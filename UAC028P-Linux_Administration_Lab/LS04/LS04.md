Linux Lab Sheet 4: User Management
Subject Code: UAC02P
IMPORTANT:
This is a worked lab guide, not a script to run from top to bottom.
Run commands individually. User/group creation and deletion require sudo.
Use only lab-only accounts; never modify or delete real system accounts.

Q1. Display current username, UID, primary GID and supplementary groups.
id
whoami
Sample output (IDs vary):
uid=1000(student) gid=1000(student) groups=1000(student),27(sudo)

Q2. Display an account entry and identify fields in /etc/passwd.
getent passwd "$USER"
Format: username:password-placeholder:UID:GID:GECOS:home-directory:login-shell
The password field is usually x; password hashes are stored in /etc/shadow.

Q3. Display password/account status without showing the password.
sudo passwd -S labuser1
sudo chage -l labuser1
Sample passwd -S output (varies):
labuser1 P 2026-10-12 0 99999 7 -1

Q4. Create labuser1 and verify.
sudo useradd labuser1
getent passwd labuser1
id labuser1
Note: useradd without -m may not create a home directory, depending on system config.

Q5. Create labuser2 with a home directory and verify ownership.
sudo useradd -m labuser2
getent passwd labuser2
ls -ld /home/labuser2
Sample: drwx------ 2 labuser2 labuser2 ... /home/labuser2

Q6. Create labuser3 with /bin/bash as login shell.
sudo useradd -m -s /bin/bash labuser3
getent passwd labuser3
The final field should be /bin/bash.

Q7. Set password for labuser1 and verify status.
sudo passwd labuser1
sudo passwd -S labuser1
Enter the password interactively; do not put passwords in this file.

Q8. Change labuser1 password and verify.
sudo passwd labuser1
sudo passwd -S labuser1

Q9. Change labuser2 shell to /bin/bash and verify.
sudo usermod -s /bin/bash labuser2
getent passwd labuser2

Q10. Change home directory first without moving contents, then with moving contents.
Choose a destination that does not already exist and is appropriate for your system.
sudo usermod -d /home/labuser2_new labuser2
The command above changes the recorded home path only; it does not move existing files.
To move the existing home contents, use -m (choose a fresh destination):
sudo usermod -d /home/labuser2_moved -m labuser2
getent passwd labuser2
sudo ls -ld /home/labuser2_moved

Q11. Create supplementary group and add labuser1.
sudo groupadd userlabgroup
sudo usermod -aG userlabgroup labuser1
id labuser1
getent group userlabgroup

Q12. Lock, verify, unlock and verify labuser3.
sudo usermod -L labuser3
sudo passwd -S labuser3
sudo usermod -U labuser3
sudo passwd -S labuser3
The status should indicate locked after -L and unlocked after -U.

Q13. Display password-aging information.
sudo chage -l labuser3

Q14. Set account expiration and verify.
sudo chage -E 2026-12-31 labuser3
sudo chage -l labuser3
Use the date assigned by your instructor if different.

Q15. Set an existing group as primary group (example: userlabgroup).
sudo usermod -g userlabgroup labuser1
id labuser1
Use an existing group that is appropriate for the exercise.

Q16. Display users and groups for a selected account.
id labuser2
groups labuser2
getent passwd labuser2
getent group userlabgroup

Q17. Delete labuser1 but keep its home directory; verify separately.
sudo userdel labuser1
getent passwd labuser1
If no account entry is printed, the account is deleted.
sudo ls -ld /home/labuser1
The home directory may exist if it was created; userdel without -r does not remove it.

Q18. Delete labuser2 and remove its home directory.
sudo userdel -r labuser2
getent passwd labuser2
sudo ls -ld /home/labuser2
The home path may be absent; if Q10 moved it, clean up the chosen destination separately.

Q19. Complete workflow (use a fresh lab-only account).
sudo useradd -m -s /bin/bash workflowuser
sudo passwd workflowuser
sudo usermod -aG userlabgroup workflowuser
id workflowuser
sudo usermod -L workflowuser
sudo passwd -S workflowuser
sudo usermod -U workflowuser
sudo passwd -S workflowuser
getent passwd workflowuser
getent group userlabgroup

Q20. Clean up only lab-created users and groups. Verify names before deletion.
Run only if you created these accounts specifically for this lab and no longer need them.
sudo userdel -r workflowuser
sudo userdel -r labuser3
labuser1 and labuser2 may already have been deleted in Q17/Q18.
Remove the group only if it is a lab-only group and has no remaining members:
sudo groupdel userlabgroup
Final verification:
getent passwd labuser1 labuser2 labuser3 workflowuser
getent group userlabgroup
No output from getent for these names means no matching entries remain.
