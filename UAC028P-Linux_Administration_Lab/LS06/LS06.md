Linux Lab Sheet 6: File Permissions & ACL
Subject Code: UAC02P
Run commands individually. Some commands need sudo.
ACL commands may require the acl package and a filesystem mounted with ACL support.

Q1. Create lab6 directory and permissions.txt.
mkdir -p lab6
touch lab6/permissions.txt

Q2. Show long listing and identify owner, group, permissions.
ls -l lab6/permissions.txt
stat -c 'Owner: %U | Group: %G | Permissions: %A (%a)' lab6/permissions.txt
Sample permissions depend on your umask and ownership.

Q3. Symbolic permissions: owner rwx, group rw-, others ---.
chmod u=rwx,g=rw,o= lab6/permissions.txt
ls -l lab6/permissions.txt
Expected mode: -rwxrw---- (760)

Q4. Numeric mode 640.
chmod 640 lab6/permissions.txt
stat -c '%A (%a)' lab6/permissions.txt
Expected: -rw-r----- (640)

Q5. Numeric mode 755.
chmod 755 lab6/permissions.txt
stat -c '%A (%a)' lab6/permissions.txt
Expected: -rwxr-xr-x (755)

Q6. Remove owner's execute permission.
chmod u-x lab6/permissions.txt
ls -l lab6/permissions.txt

Q7. Add group read and execute without changing owner permissions.
chmod g+rx lab6/permissions.txt
ls -l lab6/permissions.txt

Q8. Remove all permissions from others.
chmod o= lab6/permissions.txt
ls -l lab6/permissions.txt

Q9. Create securedata and set mode 750.
mkdir -p securedata
chmod 750 securedata
stat -c '%A (%a)' securedata
Expected directory mode: drwxr-x--- (750)

Q10. Demonstrate file vs directory permissions.
mkdir -p practice_dir
printf 'sample text\n' > practice_dir/sample.txt
chmod 640 practice_dir/sample.txt
chmod 750 practice_dir
ls -ld practice_dir
ls -l practice_dir/sample.txt
File read: read contents; file write: modify contents; file execute: run executable files.
Directory read: list names; directory write: create/delete/rename entries; directory execute: traverse/search.

Q11. Display current umask.
umask
Sample output often 0022 or 0002; record the value shown on your system.

Q12. Set umask 027 and create file and directory; verify permissions.
umask 027
touch umask_file.txt
mkdir -p umask_dir
stat -c '%n %A (%a)' umask_file.txt umask_dir
Typical result: file -rw-r----- (640); directory drwxr-x--- (750)

Q13. Restore previous umask.
First record the output of `umask` from Q11, then restore it, for example:
umask 022
umask
Replace 022 with the value you recorded in Q11.

Q14. Create lab-only user/group and ACL test file.
Choose a unique user/group name and check first that it does not already exist.
sudo groupadd aclpractice
sudo useradd -m -g aclpractice acluser
touch aclfile.txt

Q15. Display ACL and identify entries.
getfacl aclfile.txt
Entries commonly include user::, group::, other::; named user/group entries and mask appear when configured.

Q16. Grant named user read/write permission and verify.
sudo setfacl -m u:acluser:rw aclfile.txt
getfacl aclfile.txt

Q17. Grant named group read permission and verify.
sudo setfacl -m g:aclpractice:r aclfile.txt
getfacl aclfile.txt

Q18. Modify and remove a specific ACL entry.
sudo setfacl -m u:acluser:r aclfile.txt
getfacl aclfile.txt
sudo setfacl -x u:acluser aclfile.txt
getfacl aclfile.txt
Remove the named group ACL too if desired: sudo setfacl -x g:aclpractice aclfile.txt

Q19. Set default ACL on a directory and verify inheritance.
mkdir -p acldir
sudo setfacl -m d:u:acluser:rwX,d:g:aclpractice:rX,d:o::--- acldir
touch acldir/inherited.txt
getfacl acldir
getfacl acldir/inherited.txt
Default ACLs apply to newly created entries; actual effective permissions are limited by creation mode.

Q20. Complete workflow and cleanup.
mkdir -p acl_workflow
touch acl_workflow/test.txt
chmod 640 acl_workflow/test.txt
sudo setfacl -m u:acluser:rw acl_workflow/test.txt
getfacl acl_workflow/test.txt
ls -l acl_workflow/test.txt
Cleanup only the lab files/accounts you created:
sudo setfacl -b acl_workflow/test.txt 2>/dev/null || true
sudo setfacl -k acl_workflow 2>/dev/null || true
rm -rf acl_workflow acldir practice_dir securedata lab6 umask_file.txt umask_dir aclfile.txt
Remove these lab-only identities only if you created them for this exercise:
sudo userdel -r acluser
sudo groupdel aclpractice
